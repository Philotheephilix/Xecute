## Full Cut (60–90s) — Voiceover Version

### [SCENE 1: The Problem]

You bought ETH at nineteen hundred.

*[Screen flashes: **-21%**]*

Twenty-one percent. Gone.

No warning. No safety net. No way out.

That's not investing. That's gambling.

Upside: yours.

## Production Notes

| Detail | Value |
|--------|-------|
| Brag cut duration | 20 seconds |
| Full cut VO time | ~70 seconds |
| Scenes | 5 (crash → reveal → demo → flex → CTA) |
| Key visual | 3D candlestick chart crash + Buy chip on X.com |
| 3D elements | CSS 3D transform candles, perspective camera, 3D card tilts, floor plane visualization |
| Music | "Happy Beats Vol 10" by ende.app, 110 BPM, cinematic treatment |
| SFX | 8 cues: 2 bell hits, 2 soft impacts, 1 click, 3 drop sounds |
| Color palette | Dark/red `#E5484D` for crash, orange `#EF7B28` for Xecute, teal `#29CEB4` for success, warm `#FAF9F6` bg |
| Typography | Plus Jakarta Sans 800–900 display, 400–600 body |
| Design system | Neo-brutalist (2px solid #111 border, 4px hard shadow) |
| Must-show UI | 3D candle chart, Buy chip on X, buy sheet with floor slider, biometric ring, floor-active card, split flex screen |
| Beat sync | 2 strong-cue locks (15.82s, 18.01s), beat-grid for stat cards (~9.3/9.8/10.3s) |
| Audio-reactive | Subtle RMS glow on orange accents |
